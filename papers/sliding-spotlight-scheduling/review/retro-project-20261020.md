### 根因（四条，按权重）

1. **决定性测量极便宜，却被框成设计辩护题**。「质量轴是否独立」对 23 条既有前沿算 Spearman 是分钟级工作（10-18 探针 + 10-19 补测成本类合计不到半天）；此前 3 周的反复全部以论证、口径调整、卖点措辞代替测量。其中 10-19 当天的第一版结论（只测质量类）仍犯同病——**补一类口径才封死**，说明「先答后查」不是一次失误而是稳定倾向。
2. **前提洗钱链**：f_Q 的「独立性」从设计意图（09-26 spec）滑成默认事实向下传播；gate-review 各轮审的是**实现是否符合设计**，没人审「设计的前提本身是否已证」。09-30 反思已登记三病根（前提洗钱/先答后查/先推荐后摆约束），10 月仍在质量轴上重演——知道模式 ≠ 拦住模式。
3. **利益结构拖慢测量**：单目标化要改交付物、预注册主统计量、论文卖点——「测了会推翻我的卖点」的测量最容易被推迟。对比：AASR 轴（无卖点绑定）的探针 26.6 万采样点当天就测完判死。
4. **写作期在裁决未定前铺开，放大改判成本**：W2–W7 无人值守书稿 38 页按双目标模型写（10-10/11），review2 面板（10-17）在旧定位上跑——单轴裁决（10-19）使定位级内容整体进票 50 重写。**叙事性章节（摘要/贡献/主结果定义）在「主结果形态」定案前不应铺开**；方法/背景/公式章本可并行。

## 三、专题二：窗口计算——两代几何缺陷，一整代数据作废

### 时间线

### 根因（四条）

1. **两个世界问题**：合成族的全部绿验证不了真实几何链——合成窗不经轨道力学与入射角带，v2 的「全绿」在真窗第一次亮相时互相打脸。验证结论的作用域 = 生成该数据的世界的定义域。
2. **数学函数定义域的静默折叠**：asin 钝角支、clip 吞 η>64.4°、带通挖空峰值、(票 27 待修) 折返——共同形态是「函数返回了数，但不是物理答案，且不报错」。这类缺陷不会崩，只会在数据里留系统地错的值。
3. **便宜的决定性问题问得晚**：「被服务实例的交付分辨率 vs 订单」是十分钟探针，v3 世界存在两周才被问；论文正文甚至已**披露机制**（"no consumer of the achieved resolution in mode routing"）却没写后果——披露了机制 ≠ 量化了影响。
4. **跨机器可复现性**（R21 naive datetime）：帧内自洽掩盖地球相位 120° 的机器依赖——自洽 ≠ 正确，也不等于可复现。
