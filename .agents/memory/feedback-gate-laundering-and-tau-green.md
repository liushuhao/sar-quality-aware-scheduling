写「禁止某说法」的机检时，两类假绿会**静默放过**真违规：

1. **禁令标记洗白真声明**：只要声明所在**行/窗口内**出现过禁令词（禁 / forbidden / 不得），同行之后的真声明就被判为「在禁令内」而放行。实测三轮才修对——第一版 400 字符窗口，被「260 字符外一个含 forbidden 的 JSON 键」洗白；第二版改成逐行共现，被**同一行**的 `; yet the front collapse is real` 洗白；第三版才做成**位置化 + 子句作用域**（标记须在声明之前或之后，且两者之间无句/分句终止符）。
2. **子串匹配当数值比对**：`"2" in rule` 对 `"20"` 为真 ⇒ 把阈值改成 20 的规则全绿。必须 `re.search(r"...<\s*(\d+)")` 解析后比数值。

**Why**：这类检查的失败模式是「看起来在拦，实际不拦」，且**永远绿**——没有任何东西会告诉你它失效了。审查者或变异注入是唯一的发现途径。

**How to apply**：
- 每写一个文本判定，**先造一个「洗白句」和一个「干净禁令句」**，两个都必须给出预期判定（洗白句红、禁令句绿），并把洗白句作为回归用例固定下来；
- 宁可**过严**（误报）不可过松：误报会被人工一眼看出，过松是静默的；
- 判定「同一概念」时默认它**不是**同一个量，除非实测确认（本轮两次翻车：串行界是**下界**不是上界；向量 squint 与平面 squint 量纲和**零点都**不同）。

**附带的元教训**：审查者提的「事实错误」也要自己复算再采纳——本轮审查者称 `dq_all` 非零数应为 34/49，主线程独立复算为 **20/49**（他用 `>0` 无 epsilon，把 14 个 1e-16 级浮点残渣算成了质量增益）。**复算成本极低，不复算就把别人的错当自己的错改**。
