# rtk 管道计数污染

rtk hook 向 stdout 注 `[rtk] /!\ ...` 噪声行，`命令 | wc -l` 会把它计入产生假计数（实例：git log 推净误报未推 1 条）。判数一律裸命令肉眼看输出，或先 grep -v rtk；`rev-parse A B` 比对 SHA 是免管道铁证。

# 双工具派单 stale brief

双工具并行推进同一项目时，派 subagent 任务书引用的快照可能已被并行侧推进（实例：蓝图 agent 回传 P10"风险未处置"，实则 workbuddy 已跑 step8/9 关闭）。派单前扫并行侧最新工件并在任务书声明时点；回传后主线程对账最新态再采信，否定断言（"X 未处置"）必须查并行侧。
