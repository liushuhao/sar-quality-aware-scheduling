**规则**：一轨（LEO 一圈）≈ 1.5 h（693 km → 5800 s = 96.7 min，types.py:122 实录）。300 s = 卫星过**同一区域**的可见窗时长，不是一轨。目标分散后调度地平线扩展到整圈。

**Why**：agent 反复把 paper2 实验设计的 300 s 地平线（全部目标挤同一过境窗，scenarios.py:141 D08-7）当成「一轨」物理上限，2026-09-30 用户明令纠正 + 要求不盲从复核。

**复核判决（2026-09-30，代码实证）**：主体成立，四条精化：

1. **地平线 ≠ 可工作时长**：整圈 1.5 h 是调度地平线；可工作时段 = 各目标可见窗序列，窗间滑行空转，非连续成像。
2. **300 s 是设计常数非普适常数**：量级对（中入射角区域可见窗 1-5 min），但随入射掩码/高度变。
3. **分散目标换绑约束**：跨区重访靠轨道几何被动等窗口，C2 转移成本（maneuver+settle）只管同窗簇内重定向。分散 regime 绑定约束 = 窗口数量/几何 + 资源预算，禁拿 C2 算术外推分散容量。
4. **能源/固存两篇都已建模**（曾误说「都没这层」，收回）：C3 能源 Σe_i≤E_max（e=5e4/次，E_max=1e7）+ C4 固存 Σm_i≤M_max（m=5e8/次，M_max=1e11），types.py:112-138 + constraints.py:356-375，各=200 观测隐含上限。Paper1 半数密集场景绑定（2026-09-22 审查改 non-binding 论断）；paper2 全矩阵松弛。真未建模 = **下行窗（数据卸载时机）+ 热约束**；预算值默认常数，非卫星规格回源。

**How to apply**：
1. 串行上限 ~32-40 = 「单过境窗」容量，禁写/禁说成「单轨容量」。
2. paper2 稀缺叙事定位 = 「密集共窗」压力测试 regime（设计产物），非普适物理结论。
3. 第三篇（全球分散/多星/多圈）：容量主变量 = 目标分散度；绑定约束预判从 C2 窗内转移换成 C3/C4 预算 + 几何窗 + 下行窗——建模须换约束模型，不能照搬 paper2 C2 算术。禁写「单星一次只能 30 个」类普适句（见 [[paper2-matrix-run-20260930]] 红线）。
