**规则**：①任何「测量信号的解释」在判别实验做完前禁当事实写进叙事/spec/票——写时必须标「假设：待 X 判别」。②gate-review 需一路「前提审计」：列出计划继承的全部经验性主张，逐条问裁决证据在哪（待用户批后改 skill）。③推荐前先枚举硬约束（冻结资产/几何/包络/成本），约束清单空着不开口。④前沿丰富度/形状类主张（MOEA 实验尤其）必须过搜索预算阶梯收敛裁决，禁直接物理解释。

**Why**：2026-09-30 四次反转解剖：a)「平凡化=物理」经昨天核验部分支持 + 今天探针顺势写成「相变实锤」，四路 gate-review 全没拦（审楼不审地基）——晚 22 点用户一句「N≤60 活跃怎么实现」触发收敛标定，64× 预算下悬崖全反转为搜索伪影，叙事、spec D14/D15、四张票连带重裁；b)「一轨=300s」「两篇无 C3/C4」两刀都是 5 秒 grep 能挡的先答后查；c) 全球分布→f 轴→簇设计三小时翻两次，每次因约束迟到（密度几何 2000+ / 统一非必须）。

**How to apply**：叙事级主张进 spec 前自查三问——这个信号有几个候选解释？判别实验做了吗？gate-review 审到前提了吗；约束清单先行；负存在断言先 grep（见 [[feedback-negative-existence-claims]]）。做对的要保住：预注册纪律让反转零数据作废；用户追问是对抗环最有效的一环。
