2026-09-25 用户纠正：给 Claude Code（idea-spark）的交接简报写「产出必须与它一致/不要自行绕过」用词过度。

**Why:** 会话里的多数「决策」实为 ZCode 建议，未经用户逐条拍板；把建议包装成约束 = 越权代言用户。用户要的是参考输入，不是执行命令。

**How to apply:** 交接工件（简报/记忆/给其他 agent 的指令话术）分两层标记：既定事实与用户红线（有证据链/查新收口的，可写「必须」）vs 会话建议（写「建议/供参考/采纳由用户判断」）。用户明说「要它完全照做」才升硬约束。
