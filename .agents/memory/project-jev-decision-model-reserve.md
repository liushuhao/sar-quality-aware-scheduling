2026-09-26 调研沉淀（用户触发：JEV 在星上任务规划可能性 + 多星协同是否更好）。研究笔记 = `archive/jev-research-20260926/note.md`（证据清单全在文末）。

**结论**：
1. JEV 类判断模型（Choice/Score/Noul 输出，快 193×/成本 1/444，第三方实测 0.36% 费用保 99% 级联精度）适配星上规划的**元决策层**；约束校验必须保持解析硬检查（查推导是其最大短板，安全关键不容概率判断）。
2. **多星协同优于单星**：星间链路窄+间歇下，判断输出 = 天然协商原语（字节级 verdict），成本优势升格为链路可行性。新风险 = 收敛性（需确定性仲裁兜底）、相关失效（各星同款模型同错，需多样化）、级联断链（本地规则回退层必备）。
3. 硬件可行（80 亿参数模型已在轨部署、单星 0.74 POPS）；软件路径 = 自训蒸馏小判断模型（JEV 本体是云端 API 无星载版）。
4. 学术占位：多星 + 判断模型组合未见占坑（已有 = 分布式共进化 2022、LLM 集中式专利 CN120562930A）。

**Why:** 论文 2 主张（物理内生时长 + 逐模式质量 MOEA）与 JEV 正交，混入稀释主张；但该切口与星座自治国家方向（三体星座）工程拉力共振，是论文 3+ 候选。

**How to apply:** 论文 2 实验期结束后评估立项。届时表述抽象为「轻量决策模型/decision-only model」勿蹭产品名。当前前沿 = 论文 2 票 01/02 施工（A 环节已闭环），本方向不动。
