2026-09-25 用户质询「第一篇与第二篇优化目标为何不同、是否合理」的分析结论；同日用户质疑 f1 定义后三链对账修正（见文末）。

**事实（2026-09-25 对账修正版）**：Ch3（ASR 已投）目标 = f1 = Σ 所选任务优先权重（coverage profit，p∈[1,10] 均匀随机静态属性，**无质量因子**；证据 moea.py:22,168 + generate_all_scenarios.py:133 + 论文 _ablation_section.tex:54）+ f2 sinθ·cosψ 分辨率 + f3 cos³ξ NESZ 质量（条带、定时长；MOEA-2 用 f1/f2，MOEA-3 用 f1/f2/f3）。第二篇（滑聚/聚束变时长，2026-09-25 立项）= 双目标 MOEA：任务收益 + 逐模式 SAR 质量（AASR 升一级、分辨率等效孔径化）。

**差异根因（物理强制，非指标偏好）**：目标函数 = 决策空间上的物理退化算子。Ch3 决策空间（选任务+定时刻，模式/时长固定）下判别性物理 = 入射角 NESZ + 平面分辨率；第二篇决策空间加入模式/斜视角/时长后，聚束类方位谱折叠激活，AASR 升为主导退化、NESZ 失去判别性。硬搬 f2/f3 = 用条带公式给滑聚打分，SAR 成像审稿人当硬伤。**架构层面两篇收益轴同构（都是 Σ priority）**，变的只是质量算子内容——对账修正后一致性故事更强。

**辩护线（Ch2 与第二篇必须做的三件事）**：
1. Ch2 建分层统一质量模型：stripmap 特例（f2/f3）⊂ 模式感知推广（逐模式 AASR/等效孔径分辨率），不呈现两套孤立标准
2. 第二篇显式写「指标迁移」节——差异即贡献（3W 报告缺口 #3：迁移本身是贡献素材）
3. 收益项建议直接沿用 Σ priority（两篇同构，零漂移）；若第二篇收益项偏离此结构须显式论证——禁无声漂移。剩余开放点：Ch3 质量拆 f2/f3 双轴 vs 第二篇单质量目标的取舍，实验构建第一票前定

**对抗审记录**：最强反方「统一一套指标更简洁」不成立——判别性是目标函数存在理由 + Song 2025 Sensors 按模式给公式（stripmap/spotlight 表达式不同），强行统一与成像文献脱节。
